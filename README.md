# HTML-Nuggets

This was one of my first repos — a reference file I kept when learning HTML. I'm leaving it public intentionally: it's a marker of where I started.

## What's in here

**`emailjs-contact-form.html`** — A working contact form that sends submissions to a Zapier webhook. Vanilla HTML, CSS, and JavaScript. No frameworks, no dependencies. Includes:
- Input validation
- Async fetch POST to a webhook URL
- Success/error state handling on the submit button
- Clean, minimal UI with a purple gradient

When I was learning to build things, I kept a repo of useful snippets I didn't want to lose. This is that repo. If you want to see where I ended up, check out [devonclemente.com](https://devonclemente.com).
